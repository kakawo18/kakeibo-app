# 家計簿アプリ

スマホのホーム画面から使う、個人向けの家計簿アプリ（PWA）。

## 特徴

### 記録がすばやい
- 金額・カテゴリ・支払方法を選ぶだけで記録できる。支出と収入は左右のスワイプで切り替えられる
- 家賃や積立投資のような毎月の取引は「定期取引」として登録しておける。実行日を過ぎるとホームに知らせが出て、金額を確かめてから記録できる（同じ月を二重に記録しない）

### ひと目でわかるホーム
- 今月の収支・収入・支出を大きく表示し、前月比も添える
- 貯蓄率・カードの獲得ポイント・年間投資額をタイルで表示
- 支出と収入の内訳（円グラフ）、今月の支出ペースと予算、カテゴリ別の支出推移をグラフで見られる
- 月は左右のスワイプで切り替えられる。ホームと履歴のあいだで、見ている月が引き継がれる

### 履歴はリストとカレンダーで
- 月ごとの取引を、日付ごとのリストとカレンダーで切り替えて見られる。カテゴリでの絞り込みもできる

### 年間振り返り
- 年収（手取りと、税・社会保険料から逆算した額面の推定）、支出と投資、貯蓄率、累計投資額の推移を年ごとに比べられる
- 1年を選ぶと、手取りの使い道、カテゴリ別支出と前年比、月別の内訳を詳しく見られる

### 家計の実態に合わせた集計
- クレジットカードの支出は**使った月**に計上する。引き落としの月に二重に数えない
- 投資は支出と分けて集計し、立替金とその回収は収支から外す
- こうした扱いはカテゴリ名ではなく、カテゴリに付けた「役割」（給与収入・投資・立替金など）で決まる。カテゴリは自由に作れて、名前を変えたり使わなくなって片づけたりしても、過去の集計は変わらない
- カードごとの還元率から、獲得ポイントを自動で計算する

### 速く、オフラインでも使える
- 起動時は直近13か月分だけを読むので、記録が何年分たまっても起動の速さは変わらない
- 電波が無くても閲覧・記録・編集ができる。記録した内容は端末に保存され、通信が戻ると自動で送信される

### 安心して続けられる
- 複数の端末で同じデータを自動で同期する
- 全取引を CSV で書き出し・取り込みできる（バックアップや移行に）
- 自分のデータは自分しか読み書きできない。ログアウトすると端末に残した家計データも消える
- ライト / ダークの両方のテーマに対応
