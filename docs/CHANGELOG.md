# 変更履歴

変更を入れたら `package.json` の `version` を更新し、このファイルの先頭に節を追加する（運用ルールは `AGENTS.md` の「バージョン管理」を参照）。

## [5.1.0] - 2026-08-16

### 追加
- **開発元表記**: 画面下部のバージョン表示に `© Gorillaburg Inc.` を追加

### 修正
- **カテゴリ別支出推移グラフ**: 比較カテゴリの選択がリロードで既定（支出Top3）に戻る不具合を修正。選択を localStorage に保存する `usePersistedState` フックを追加し、保存後に改名・削除されたカテゴリは表示時に除外する

### 技術的変更
- 変更ごとにバージョンと変更履歴を更新する運用を `AGENTS.md` に明記
- `docs/CHANGELOG.md` の記載が 1.0.0 で止まっていたため、1.1.0 〜 5.0.0 を履歴から補完

## [5.0.0] - 2026-07-03

### 追加
- **設定ページ (/settings)**: カテゴリ・支払方法・月間予算をアプリ上から編集可能に
- **ユーザー設定のデータモデル**: Firestore の `users/{uid}/settings/app` と `SettingsContext` を追加
- **月次支出ペースグラフ**: 週別累計の積み上げ棒グラフ + 理想ペースライン

### 改善
- **UI 全面刷新**: デザインシステム "Quiet Ledger"（フラットな面 + ヘアライン境界）を導入
- **集計ロジックを役割ベースへ変更**: カテゴリ名の文字列一致をやめ `CategoryRole` で判定するようにし、カテゴリを自由に変更しても集計が壊れないように
- PWA の最適化と円グラフの UI 改善
- 旧ハードコード定数を削除しドキュメントを整備

### 修正
- ダークモードで収支の意味色が白飛びする問題
- スマホ入力時に金額欄で数字が重複する不具合
- 前月比の計算バグ、CSV 入出力の不具合
- Textarea のクラッシュ、ログイン失敗時に dev オーバーレイが出る問題
- 月次支出ペースから家賃・投資（定期課金）を除外

## [2.0.0] - 2025-12-28

### 追加
- **立替金カテゴリ**: 年間集計から除外する仕組みを追加
- **カテゴリ別支出推移グラフ**: 支出Top3を自動選択して比較表示

### 改善
- 貯蓄率の算出にボーナスを含めるよう変更し、年間収支に注記を追加
- ダッシュボードの余白を詰めた高密度レイアウト
- モバイルの円グラフを大型化（半径 105px）
- カレンダーのグリッド線を細く均一に

### 修正
- 月次収支を発生主義（収入 − 支出）に統一
- ツールチップの NaN% 表示
- 定期取引の重複判定を名称・説明の一致で厳密化
- 投資の注記を年間支出側へ移動

## [1.1.0] - 2025-12-27

### 追加
- モバイル UI を Bento Grid レイアウトへ刷新
- 貯蓄率・貯蓄額の表示とグラフ改善
- ダークモード対応と年月移動 UI の改善

### 技術的変更
- Next.js を 16.1.1 に更新（CVE-2025-66478 対応）
- ESLint / ビルドエラーの整理

## [1.0.0] - 2025-10-26

### 追加
- **バージョン表示機能**: アプリ下部にバージョン情報を表示
- **VersionDisplayコンポーネント**: バージョン情報を表示する新しいコンポーネント

### 改善
- **年月移動のパフォーマンス**: 月選択時のスクロール無効化で反応速度を向上
- **取引フォームのモバイル最適化**:
  - **NativeSelectの採用**: モバイルではネイティブselect要素を使用し、スクロール問題を根本解決
  - デスクトップでは従来のSelectコンポーネントを維持（検索機能付き）
  - フォントサイズを16pxに統一（ズーム防止）
  - タップ領域を48pxに拡大
- **取引フォームのUI改善**:
  - **収入入力時に支払方法を非表示**: 収入には支払方法が不要なため、フォームをシンプル化
  - 収入⇔支出切り替え時に支払方法を自動クリア
- **カテゴリ構造の最適化**:
  - **光熱費カテゴリを削除**: 電気代、ガス代、水道代を固定費のサブカテゴリに統合
  - より直感的なカテゴリ分類
- **SegmentedControlの最適化**: モバイルでのタップ領域を拡大
- **Textareaの改善**: 自動サイズ調整とモバイル最適化
- **カレンダーのタップ反応改善**:
  - タップハイライトの最適化
  - トランジション速度の高速化（0.15s）
  - touchActionの追加で誤タップを防止
- **グローバルCSS改善**:
  - ボタンとクリック可能要素のタップ反応を改善
  - Selectドロップダウンのタップ反応を最適化

### 修正
- **モバイルPWAでの入力問題**: タッチ操作の安定性を向上
- **Selectコンポーネントの不安定性**: NativeSelectの採用で長いリストのスクロール問題を解決
- **Textareaのエラー**: minHeightスタイルを削除し、minRowsプロパティのみ使用

### 技術的変更
- Next.js: 15.3.4 → 15.5.6（セキュリティ修正）
- TypeScript target: ES2017 → ES2020
- ESLint設定の強化
- 環境変数管理の改善
